# SmartCart – Smart Shopping List Manager

A simple Flutter UI project for the UID subject.

## Features
- Smart shopping list dashboard
- Add shopping items
- Select item category
- Mark items as completed
- Swipe to delete items
- Categories screen
- Profile screen
- Bottom navigation
- Material 3 UI
- Responsive Flutter layout

## Run
1. Install Flutter.
2. Open this folder in VS Code or Android Studio.
3. Run `flutter pub get`.
4. Run `flutter run`.
